# Pluribus

Talent platform of Tony and SL Benfica. React + TypeScript + Vite, Supabase (Postgres, Auth, RLS), deployed on Netlify.

- `src/` — web app (staff environment and coach portal)
- `supabase/migrations/` — database schema, access rules and seed data, applied in order
- Architecture: see the "TonyRW system architecture" document

Stage 1: foundations — login, owner setup, coach sign-up and approval, Users, Settings, full menu.
